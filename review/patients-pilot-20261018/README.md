# Pacientes: piloto visual

Cuatro renders de widgets reales, con cuenta DEMO y pacientes, pesos y alergia
ficticios: `lista-light.png`, `lista-dark.png`, `ficha-light.png`, `ficha-dark.png`.
La ficha se desplaza hasta «Expediente abierto» para mostrar el historial; la lista
sigue accesible arriba. Tutor pendiente representa un dato realmente ausente de
esta fixture, no un contacto real.

No son capturas de Android ni una comprobación contra Supabase. Se utiliza la
fuente local de previews ya existente. Reproducir:

`flutter test test/previews/capture_patients_pilot.dart`
