# Planeación financiera: simulador mensual

`entrada.png` muestra el formulario vacío y `resultado.png` un escenario
estrictamente ficticio: ingresos 50000, fijos 20000, variables 10000,
depreciación 5000, inversión 100000, fondos 33500 y reserva 1500 MXN.
No hay datos reales ni persistencia. Son renders de widgets, no capturas de Android.

Reproducir: `flutter test test/previews/capture_financial_planning.dart`.
