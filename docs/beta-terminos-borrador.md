# Términos de beta — borrador para aprobación

Este texto está preparado para revisión de la propietaria. No está publicado ni se pide aceptarlo como definitivo.

- La beta de VetDosis Pro es una prueba privada para cuentas aprobadas o invitadas. No redistribuyas la aplicación ni compartas tu acceso.
- Usa únicamente datos ficticios durante esta prueba. No registres información real de pacientes, propietarios o terceras personas.
- La inscripción dura 60 días desde su aceptación registrada por el servidor. Se mostrará un aviso durante los últimos siete días. Al vencer, conservarás la consulta y exportación de los datos para los que mantengas autorización; no podrás registrar cambios.
- Cada publicación de la aplicación beta puede requerir actualización al cumplir 90 días o cuando se establezca una versión mínima. Esto no renueva la inscripción individual.
- Aprobar tu correo o concederte acceso beta no verifica una cédula ni autoriza procedimientos clínicos. Los permisos y la habilitación profesional se comprueban por separado.
- Los datos no se eliminan automáticamente al vencer la beta. La política definitiva de conservación, solicitudes de eliminación y aviso de privacidad quedan pendientes de revisión y publicación; no se promete conservación perpetua.
- Las funciones y los datos de referencia pendientes de verificación deben identificarse como tales. La beta no debe usarse para tomar decisiones clínicas con datos ficticios o sin verificar.

Pendiente antes de publicar: identidad y medio de contacto de la responsable del tratamiento de datos, aviso de privacidad aplicable y confirmación de este texto por la propietaria. La app solo mostrará una versión publicada, con hash, y registrará su aceptación exacta.
